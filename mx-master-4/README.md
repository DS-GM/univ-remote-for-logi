# MX Master 4 config

**For the Logitech MX Master 4 only.** Gesture button is CGEvent **6**, the
thumb-rest Actions Ring pad.

On an MX Master 3S or older this config does nothing, because on those the
thumb rest is button 5. Use [`../mx-master-3s/`](../mx-master-3s/) instead.

Install from the repo root:

```bash
./switch.sh 4
```

Full documentation, including the button-number table and why the two
generations differ, is in the [top-level README](../README.md).
